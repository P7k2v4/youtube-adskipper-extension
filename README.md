# YouTube Ad Skipper Extension

A browser extension that automatically skips to the end of YouTube ads so you don’t have to sit through them.  

---

## Features

- Automatically detects when a YouTube ad is playing.  
- Skips the ad after a very short delay (once you can skip / when it’s safe).  
- Lightweight — minimal footprint.  
- Works on the desktop version of YouTube.  

---

## Installation

> ⚠️ This is a custom extension. You may need to enable “Developer mode” in your browser’s extension settings.

### For Chrome / Chromium-based browsers:

1. Clone or download this repository.  
   ```bash
   git clone https://github.com/P7k2v4/youtube-adskipper-extension.git
2. Open chrome://extensions/ in your browser.

3. Enable Developer mode (usually a toggle in the top-right).

4. Click “Load unpacked”.

5. Select the folder where you downloaded this extension (the folder containing manifest.json and content.js).

6. The extension should now be loaded. YouTube ads will be skipped automatically from then on

### For Mozilla Firefox:

1. Clone or download this repository.
   ```bash
   git clone https://github.com/P7k2v4/youtube-adskipper-extension.git
2. Open Firefox and type about:debugging#/runtime/this-firefox in the address bar.

3. Click “Load Temporary Add-on…”.

4. Select the manifest.json file inside the downloaded extension folder.

5. The extension will now run in your Firefox session.
